# sistema-de-gestion-laboratorio

Este es un sistema para la gestion de prestamos de un laboratorio de electronica para mejorar el flujo en el registro de prestamos de manera eficiente evitando la tarea de agregar manualmente por medio de un excel.

# Instalacion

Para la instalacion y uso del proyecto primero clonemos el repositorio de la siguiente manera

```bash
git clone https://github.com/brandon-alexis/sistema-de-gestion-laboratorio.git
```

o

```bash
git clone git@github.com:brandon-alexis/sistema-de-gestion-laboratorio.git
```
